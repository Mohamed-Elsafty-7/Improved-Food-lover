# Improved Food Lover — Interactive Restaurant Website

Improved Food Lover is an enhanced version of the original Food Lover project. It introduces JavaScript-driven interactions while retaining the restaurant website's visual identity.

## 🌐 Live Demo

[Visit Improved Food Lover](https://mohamed-elsafty-7.github.io/Improved-Food-lover/)

## ✨ Features

- Restaurant landing page and navigation.
- Food menu data organized in JavaScript.
- Food image gallery with image navigation and a close interaction.
- Offer carousel with previous and next controls.
- Contact form with client-side input validation.
- Custom styling and food imagery.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Font Awesome 6

## 🚀 Run Locally

```bash
git clone https://github.com/Mohamed-Elsafty-7/Improved-Food-lover.git
```

Open `index.html` in your browser.

## 📚 What I Practiced

- Separating JavaScript logic into external files.
- Handling user interactions and browser events.
- Manipulating the DOM.
- Implementing image navigation and carousel controls.
- Validating form fields with JavaScript.
- Organizing menu data in arrays and objects.

## ⚠️ Current Limitations

The contact form performs client-side validation and displays a confirmation alert, but it does not send the message to a server. The website is a front-end project rather than a complete restaurant ordering system.

## 🔮 Possible Improvements

- Connect the contact form to a back-end service.
- Add functional menu filtering or ordering.
- Improve accessibility and responsive behavior.
- Replace demonstration text with final restaurant content.
